# Leonardo AI 详细介绍

## 1. 这个工具是什么

Leonardo AI 是一款基于生成式人工智能的图像创作平台，由澳大利亚团队 Leonardo.Ai 开发，于 2022 年底正式上线。它允许用户通过输入文字提示（Prompt），快速生成高质量的图像、插画、概念设计、游戏素材等视觉内容。

Leonardo AI 最初以“游戏美术素材生成”为切入点，因此在对游戏资产、角色设计、道具图标等方向的支持上较为突出。2024 年，Leonardo.Ai 被 Canva 收购，但其产品仍独立运营，并持续更新模型与功能。

它的底层使用多种自研及第三方扩散模型（如 Phoenix、Kino XL、Vision XL、AlbedoBase XL 等），并支持用户训练自己的专属模型。

---

## 2. 适合谁用

- **游戏开发者 / 独立游戏团队**：快速生成角色、道具、场景、图标等素材。
- **插画师 / 概念设计师**：用于灵感探索、草图生成、风格参考。
- **平面设计师 / 营销人员**：制作海报、社交媒体配图、广告视觉。
- **内容创作者 / 自媒体人**：为视频、文章、播客配图。
- **AI 绘画爱好者**：想尝试不同模型、风格、LoRA 训练的用户。
- **产品/建筑/服装设计从业者**：用于早期概念可视化。

不太适合：
- 对图像版权、商用授权有极高法律要求且不愿仔细阅读条款的团队。
- 完全不想学习提示词、只想“一键出图”的纯小白（可能需一定学习成本）。

---

## 3. 核心功能

**① 文生图（Text to Image）**
输入文字描述，选择模型、风格、尺寸，生成图像。

**② 图生图（Image to Image）**
上传参考图，结合提示词进行风格迁移或再创作。

**③ 实时画布（Realtime Canvas）**
边画边生成，适合快速草图迭代。

**④ 模型选择与切换**
提供多种官方模型，如 Phoenix、Kino XL、Vision XL、AlbedoBase XL、Anime XL 等，分别偏向写实、动漫、电影感、游戏资产等方向。

**⑤ 自定义模型训练（Fine-tuned Models）**
用户可上传自己的数据集，训练专属风格模型，这是 Leonardo 的一大亮点。

**⑥ Elements / LoRA 支持**
可叠加风格元素（如光影、材质、画风）来微调输出。

**⑦ 提示词优化与反向提示**
内置 Prompt Magic、负面提示词等功能，提升出图质量。

**⑧ 图像编辑工具**
包括扩图（Outpainting）、局部重绘（Inpainting）、背景移除、放大（Upscale）等。

**⑨ 社区与素材库**
可浏览、复制他人提示词与参数，学习效率高。

**⑩ API 与团队协作**
付费用户可接入 API，团队版支持多人协作与资产管理。

---

## 4. 优缺点

**优点：**
- 免费额度充足，适合长期试用与轻度创作。
- 模型种类丰富，尤其适合游戏美术与动漫风格。
- 支持训练自定义模型，风格可控性强。
- 出图速度快，界面友好，社区活跃。
- 被 Canva 收购后，生态整合潜力大。

**缺点：**
- 写实人像、复杂手部、精细文字仍有瑕疵。
- 免费版生成速度慢、排队时间长、商用权限受限。
- 部分高级功能（如高分辨率放大、私密生成）需付费。
- 模型风格偏向“美漫/游戏/奇幻”，偏写实摄影或东方水墨等风格不如部分竞品。
- 版权与商用条款需用户自行仔细阅读，不同计划差异较大。

---

## 5. 怎么开始用

1. **访问官网**：打开 leonardo.ai。
2. **注册账号**：可用 Google、Apple、Microsoft 或邮箱注册。
3. **进入控制台**：登录后进入 Web 界面（也有移动端 App）。
4. **选择模式**：从 Image Generation 开始，选择模型、尺寸、风格。
5. **输入提示词**：用英文描述画面内容、风格、光线、构图等。
6. **调整参数**：如采样步数、引导强度、负面提示词。
7. **生成与迭代**：点击生成，查看结果，可继续微调或使用图生图。
8. **进阶尝试**：训练自己的模型、使用 Realtime Canvas、API 等。
9. **下载与使用**：注意查看当前计划下的商用许可与版权说明。

**小建议**：
- 提示词尽量具体：主体 + 风格 + 光线 + 镜头 + 情绪。
- 多参考社区热门作品的提示词与参数。
- 免费用户优先使用较高性价比模型，避免频繁高分辨率生成。

---

## 6. 免费还是付费

Leonardo AI 采用 **Freemium（免费增值）** 模式。

**免费版：**
- 每日赠送一定数量的 Token（代币），用于生成图像。
- 可用基础模型与部分高级模型。
- 生成速度较慢，排队优先度低。
- 商用权限有限，需遵守其免费条款。

**付费版（大致分为以下几档）：**
- **Apprentice / Artisan / Maestro 等**：按月订阅，Token 更多、生成更快、可用高级模型、私密生成、商用授权更明确。
- **团队版 / 企业版**：支持多人协作、API 调用、集中计费等。
- 具体价格与 Token 数量会随官方调整变化，建议以官网最新定价为准。

**总结**：
轻度体验、学习、非商用创作 → 免费版足够。
高频使用、商用项目、需要私密与高速 → 建议付费。

---

**一句话总结**：
Leonardo AI 是一款模型丰富、可训练自定义风格、对游戏与动漫美术特别友好的 AI 绘画平台，免费可用但商用与高级功能需付费，适合从爱好者到专业团队的广泛用户。
